# MultiTool Mirror — сборки для телефона

Зеркало чата **MultiTool** (Windows) на Android-телефоне по локальной сети WiFi: список чатов,
живой чат, отправка сообщений и вложений, «Стоп», ответы на вопросы и запросы разрешений,
уведомления. Приложение бесплатное, репозиторий открыт для скачивания обновлений.

## Что скачать

| Файл | Кому |
| --- | --- |
| `multitool-mirror-<версия>.apk` (в разделе [Releases](../../releases/latest)) | на телефон |
| папка [`bridge/`](bridge) | на компьютер с MultiTool |

Номер версии стоит прямо в имени файла, поэтому видно, что именно скачано: например
`multitool-mirror-0.1.21.apk`. Страница последней версии:

```
https://github.com/slep0y/multitool-mirror-releases/releases/latest
```

## Что нужно

- Компьютер с Windows и установленным MultiTool (приложение должно хотя бы раз запускаться).
- Телефон с Android 8.0 (API 26) или новее.
- Телефон и компьютер в одной сети WiFi. Соединение локальное: трафик не выходит в интернет.
- На компьютере — Node.js не нужен: мост работает на встроенном движке MultiTool.

## Что умеет приложение

- список всех чатов с компьютера и живой чат: ответы появляются сами;
- отправка сообщений и вложений (фото из галереи, файл, снимок с камеры);
- «Стоп» — прервать текущий ответ;
- ответы на вопросы ассистента и на запросы разрешений, в том числе прямо из уведомления;
- markdown в ответах: код, жирный, курсив, списки, цитаты, ссылки и **таблицы** — таблицы рисуются
  сеткой с заголовком, выравниванием колонок и горизонтальной прокруткой;
- несколько компьютеров с переключением в один тап;
- обновление приложения из самого приложения.

## Установка на компьютер (один раз)

1. Скачайте папку `bridge/` из этого репозитория (кнопка **Code → Download ZIP** или `git clone`),
   распакуйте в любое место, например `C:\multitool-mirror`.
2. Подключите плагин-мост к движку MultiTool. Откройте PowerShell в папке `bridge` и выполните:

   ```powershell
   pwsh -File .\install-plugin.ps1
   ```

   Скрипт делает резервную копию конфига `%USERPROFILE%\.config\gigatool\opencode.json` рядом с
   оригиналом (`*.bak-mirror-ГГГГММДД-ЧЧММСС`) и добавляет в него путь к `multitool-mirror.mjs`.
   Убрать плагин: `pwsh -File .\install-plugin.ps1 -Remove`.
3. Разрешите входящие подключения в брандмауэре Windows — **от имени администратора**:

   ```powershell
   pwsh -File .\firewall.ps1
   ```

   Создаются правила для частных сетей: TCP 8799 (HTTP и поток событий) и UDP 8798 (поиск
   компьютера в сети).
4. **Перезапустите MultiTool** — плагины движок читает только при старте. Мост поднимается вместе
   с ним и пишет служебные файлы в `%LOCALAPPDATA%\MultiTool-Mirror\`.
5. Проверьте, что мост жив: откройте `http://127.0.0.1:8799` в браузере на компьютере. На странице
   виден код сопряжения вида `ABCD-1234`.

Состояние моста в любой момент:

```powershell
pwsh -File .\status.ps1
```

## Установка на телефон

1. Скачайте `multitool-mirror-<версия>.apk` из последнего релиза и откройте файл на телефоне. Android попросит
   разрешить установку из этого источника — разрешите для браузера или файлового менеджера.
2. Запустите приложение.

## Сопряжение

1. На компьютере посмотрите код: на странице `http://127.0.0.1:8799` или через `status.ps1`.
2. В приложении нажмите «Найти компьютер в сети» (или введите адрес компьютера вручную) и введите код.
3. Телефон получит долгоживущий токен, а код сопряжения сразу сменится.

Отвязать телефон: меню (точки в правом верхнем углу) → «Отвязать этот компьютер»; на компьютере все
устройства разом — файл `%LOCALAPPDATA%\MultiTool-Mirror\store.json` (удалить). Сменить код — кнопка
на странице моста.

## Несколько компьютеров

Приложение запоминает каждый компьютер, с которым сопрягалось, — имя, адрес и токен. Код сопряжения
нужен один раз на машину; дальше переключение идёт без кодов:

- меню → «Компьютеры» — список сохранённых машин с адресами (текущая помечена «● … сейчас»),
  тап переключает; там же «Добавить» и «Удалить…»;
- на экране подключения сохранённые компьютеры видны кнопками — переключение в один тап;
- если сохранённый компьютер виден в сети, а текущий не отвечает, приложение подключается к
  видимому само (удобно, когда работаете то дома, то в офисе);
- «Отвязать этот компьютер» убирает только текущую машину и сразу переходит на другую сохранённую.

На каждом компьютере при этом нужен свой мост (`bridge/`, пункты 1–5 ниже) и своё сопряжение.

## Обновление приложения

- Проще всего — из самого приложения: меню (кнопка с тремя точками в правом верхнем углу) → пункт
  «Обновить версию». Приложение проверит последний релиз, покажет новую версию и её размер, скачает
  APK с прогрессом и откроет установщик. Если версия уже последняя, так и напишет.
- Последняя версия всегда лежит в разделе [Releases](../../releases/latest); там же `CHANGELOG.md`.
- Файл в релизе назван с номером версии — `multitool-mirror-0.1.21.apk`; имя меняется вместе с версией.
- Программа, которой нужен номер последней версии, может спросить GitHub API:
  `https://api.github.com/repos/slep0y/multitool-mirror-releases/releases/latest`
  (поле `tag_name`, файл — в `assets[].browser_download_url`).
- Обновление ставится поверх установленного приложения **без удаления** и **без нового
  сопряжения**: все релизы подписаны одним и тем же ключом (см. ниже).

## Версии

Версия моста на компьютере и версия приложения независимы:

- версия моста — из папки `bridge/`, видна в `GET /healthz` и в `status.json`;
- версия приложения — из `CHANGELOG.md`, видна в приложении.

Обновление моста: замените файлы в `bridge/` и перезапустите MultiTool. Обновление приложения:
скачайте новый APK. Обновлять оба сразу нужно редко — мост совместим с приложением на одну-две
версии вперёд и назад.

## Подпись APK

Все релизы подписаны одним постоянным ключом (`CN=Android Debug`,
SHA-256 `9877b9a75a1d139bddc65df38ac37200724c4b74ac9abb834e8f5492efa00ecc`). Поэтому обновления
встают поверх предыдущей версии. Проверить подпись скачанного файла:

```powershell
& "$env:LOCALAPPDATA\Android\Sdk\build-tools\35.0.0\apksigner.bat" verify --print-certs .\multitool-mirror-0.1.21.apk
```

Если в будущем ключ придётся сменить, Android откажется ставить обновление поверх: тогда удалите
приложение на телефоне, установите APK заново и сопрягите телефон ещё раз.

## Известные проблемы и фиксы

Разобранные проблемы и готовые шаги — в [`FIXES.md`](FIXES.md). Ассистенту достаточно сказать
«прочитай FIXES.md и примени фикс № 1».

- **Фикс 1 — «ассистент не видит запросы разрешений».** Симптом: на телефоне карточки с
  «Разрешить» приходят и нажимаются, а ассистент говорит, что запросов не было. Причина в способе
  проверки: `GET /api/permissions` показывает только текущую очередь (после ответа она пуста), а в
  потоке `GET /api/events` тип события лежит в `data.type`. Инструмент проверки:
  `node tools\watch-permissions.mjs "$env:TEMP\gigatool\perm-events.log" 240` (нужен Node.js 22+).

## Безопасность и ограничения

- Соединение идёт по обычному HTTP внутри вашей сети WiFi: трафик не шифруется, но наружу не выходит.
- Мост отвечает только на частные адреса (`192.168.*`, `10.*`, `172.16–31.*`, локальные).
- Код сопряжения меняется после каждого успешного подключения; токены устройств хранятся только на
  компьютере, в `%LOCALAPPDATA%\MultiTool-Mirror\store.json`.
- Плагин не загружается в безопасном режиме MultiTool (`--safe-mode`, `GIGATOOL_SAFE_MODE=1`).
- Выданный телефону доступ — полный контроль над чатом: чтение, отправка, остановка ответа, ответы
  на запросы разрешений. Давайте код сопряжения только своим устройствам.
- Приложение ничего не отправляет в интернет, кроме проверки обновлений (если эта функция включена).

## Состав репозитория

| Путь | Что это |
| --- | --- |
| `bridge/multitool-mirror.mjs` | плагин-мост: HTTP + поток событий, сопряжение, доступ к чатам |
| `bridge/install-plugin.ps1` | подключить плагин к конфигу MultiTool (с резервной копией) |
| `bridge/status.ps1` | код сопряжения, адреса компьютера, подключённые устройства |

| `tools/watch-permissions.mjs` | наблюдение за потоком событий моста: видно запросы разрешений и ответы |
| `FIXES.md` | разобранные проблемы и готовые шаги (фикс 1 — «не видно запросов разрешений») |
| `CHANGELOG.md` | версии приложения |
| Releases | APK по версиям |
